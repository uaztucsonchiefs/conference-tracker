      How module credit works

      One required and one optional credit per resident per block. Only mark completions you have verified. Clinic weeks come from the workbook’s PEAC group assignments; prelim exclusions carry forward. Switching blocks or weeks clears unsaved selections.

      Coordinator work queue

      Needs attention

      Review proof, resolve missing attendance, fill NI identifiers and follow up on export or job failures.

      AHD attendance check

      A half-day only counts when all three hours are checked in. Residents with 1–2 of 3 hours on an AHD date are usually a missed scan, not a real absence — review them here and credit the missing hour(s) if appropriate. Cancelled and deleted AHDs never count toward the total, and neither do 7/2/2026 or the last two weeks of the year.

      Advanced AHD diagnostics
      Integrity & duplicate checks
      Duplicate cleanup
      ▸ Duplicate credits (resident credited twice)

      Finds anyone credited more than once for the same conference and removes only the extra credit — one is always kept, sign-ins are never lost. This is the one to run if points look inflated.

      ▸ Duplicate conference listings

      Finds listings that repeat the same date, type, title, and site. Removes only empty copies — any copy with check-ins is kept, and at least one of every offering survives.

      Check-in integrity · shared devices

      One phone checking in several different residents for the same session is the signature of code-sharing. Live check-ins from a shared device are already flagged into the Review queue automatically; this scans the whole term (including anything the live check missed) and shows who turns up on a shared device repeatedly.

      Program handoff

      Ready for the next chief

      Record program access and verify it with the incoming chief. Saving this checklist does not transfer account ownership.

      Install or transfer scheduled jobs

      Sign into Apps Script with the program-managed account that should own the jobs. Run installProgramTriggers once and authorize it. The outgoing owner should remove their old project triggers from their own account. Apps Script only lists the current account’s triggers, so both owners must check before handoff. This also enables immediate totals-cache invalidation after workbook edits.

      Weekly NI preparation runs only if enabled here; it saves a file, and does not submit anything to NI.
